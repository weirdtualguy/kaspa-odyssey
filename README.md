# Kaspa Odyssey

Real-time generative art driven by the Kaspa blockDAG network health state.

Every particle, pulse, and whisper is the network breathing in real time. Not a dashboard — a decentralized organism visualized as atmospheric cinematic art.

## Live Demo

https://weirdtualguy.github.io/kaspa-odyssey/

## How It Works

- Fetches live data from `api.kaspa.org/info/health` every 8 seconds
- Translates network metrics (blue score diff, sync state, block time) into visual systems
- Single HTML file, no frameworks, pure Canvas 2D
